Stránky, které ti udělá agent.

Popros svého AI agenta o nákupní seznam, seznam věcí na cestu, plán výletu nebo malou aplikaci. Udělá stránku, zveřejní ji zašifrovanou a pošle ti odkaz. Otevřeš ji v mobilu, odškrtáváš a dopisuješ. Agent si pak přečte, co jsi změnil.

Klíč je část odkazu za znakem #. Prohlížeč tuto část nikdy neposílá na server, takže relaye a úložné servery mají jen nečitelné bajty. Stránku otevře každý, kdo má odkaz, a nikdo jiný.

Chceš, aby ti agent postavil celý web, který si pak upravuješ sám? To je jiný úkol, s vlastním skillem: nsite-clay-web-builder.zip. Nebo mu dej llms.txt.

Nastav to jedním krokem.

Funguje s každým agentem, který umí spouštět příkazy: Claude Code, Codex, Hermes Agent a dalšími. Stačí Node.js 18 nebo novější. Žádný účet, žádný tvůj klíč, žádný vlastní server. Skill je jeden zip soubor.

Stáhnout nsite-artifacts.zip

Claude Code nebo Codex: jeden příkaz

curl -fsSL -o /tmp/nsite-artifacts.zip https://nsite-clay.cypherpunk.today/skills/nsite-artifacts.zip &&
unzip -oq /tmp/nsite-artifacts.zip -d ~/.claude/skills &&
node ~/.claude/skills/nsite-artifacts/scripts/artifact.mjs help

Ten rozbalí skill do tvé složky se skilly a ověří, že běží. Pro Codex použij ~/.codex/skills místo ~/.claude/skills. Pak otevři novou relaci, aby agent skill viděl. Stejný nástroj je i v balíčku pro příkazovou řádku: npx nsite-clay artifact help. V Claude.ai nahraj zip v Nastavení, Schopnostech, Skills, pokud ti tvůj plán dovoluje agentovi spouštět kód a připojovat se k síti.

Nebo vlož tohle svému agentovi

Nainstaluj skill nsite-artifacts. Stáhni https://nsite-clay.cypherpunk.today/skills/nsite-artifacts.zip
a rozbal ho do své složky se skilly tak, aby tam existoval nsite-artifacts/SKILL.md.
Pokud složku se skilly nemáš, rozbal ho někde trvale a zapamatuj si kde. Pak
přečti SKILL.md a řiď se jím vždy, když tě požádám o seznam, plán nebo malou
stránku, kterou si otevřu v mobilu, můžu sdílet, komentovat nebo upravovat sám.
Ověř, že funguje, příkazem: node <ta složka>/scripts/artifact.mjs help

A pak už jen řekni.

  • Udělej mi nákupní seznam na sobotu, který si budu odškrtávat v mobilu: mléko, chleba, káva, olivový olej.
  • Dej náš výlet do Lisabonu na stránku, kterou budeme moct upravovat já i partnerka. Týden po návratu ji smaž.
  • Co ještě zbývá na nákupním seznamu?
  • Udělej mi malý sledovač návyků na každý den a v neděli mi řekni, jak dopadl týden.
  • Sdílej seznam věcí na cestu s npub1…, ať ho otevře jen on.
  • Seznam už nepotřebuju, smaž ho.

Agent napíše stránku, nástroj ji zašifruje a zveřejní. Model se klíče nikdy nedotkne: klíč existuje jen v odkazu, který nástroj vrátí. Každá stránka má datum zániku, 30 dní, pokud neřekneš jinak.

Řekni, co má být jinak.

Každá stránka, kterou můžeš upravovat, má v rohu tlačítko Komentáře. Označ pár slov a stiskni Komentovat, nebo vyber část stránky a napiš, co chceš změnit. Uloží se spolu se stránkou. Pak řekni agentovi, že jsi komentoval: najde každý komentář i přesně, kde se nachází, provede změnu, odpoví pod komentářem a označí ho jako vyřešený.

Stránku můžeš měnit i sám, v prohlížeči. Agent si drží kopii stránky tak, jak ji viděl naposledy, takže přesně ví, co jsi změnil, a umí přizpůsobit zbytek stránky.

Odkaz pro úpravy pošli těm, kdo mají komentovat, protože komentář se ukládá spolu se stránkou. Kdo má jen odkaz pro čtení, může se podívat, ale komentovat nemůže.

Kdo ji může otevřít.

  • Kdokoli s odkazem. Výchozí možnost. Odkazy jsou dva: na čtení a na úpravy. Ten na úpravy pošli těm, kdo mají stránku měnit, a ten na čtení všem ostatním.
  • Jen určití lidé. Dej agentovi jejich npuby. Odkaz pak nenese žádný klíč a každý se pro otevření stránky přihlásí vlastním Nostr klíčem.
  • Všichni. Jen když chceš něco veřejného, třeba stránku na svůj web. Pak není šifrovaná.

Když chceš někomu vzít přístup a odkaz už má, je potřeba nový klíč, protože ten starý zná. Agent to udělá za tebe: přesune stránku na nový odkaz a starý smaže.

Zámek na stránce.

Každá šifrovaná stránka má v dolním rohu malé tlačítko se zámkem. Pokud jsi ji otevřel odkazem na úpravy, ukáže oba odkazy ke zkopírování, kdy stránka zanikne a kdo další ji může otevřít.

Odtud můžeš přidat člověka podle jeho npubu nebo stránku hned smazat, bez agenta.

Přes odkaz na čtení nabídne jen ten odkaz a datum zániku. Kdo se přihlásil jako člen, nevidí žádné odkazy, takže stránka sdílená s konkrétními lidmi se neroznese jako odkaz.

Když dva uloží ve stejnou chvíli, druhé uložení se odmítne a ten člověk dostane výzvu, aby stránku znovu načetl. Nic se nepřepíše.

Uklízí po sobě.

  • Jedna verze. Uložení si verzi, kterou nahradilo, ponechá dva dny, protože brána ji ještě může podávat ze své cache, a pak ji smaže. Seznam odškrtaný stokrát tak nakonec zabere místo jako jeden a servery drží jen to, co se používá.
  • Zánik. Stránka nese své datum konce a agent jednou denně smaže všechno, čemu už uplynulo. Nastavuje se to jednou a skill agentovi řekne jak.
  • Smazat znamená smazat. Ať přes zámek, nebo přes agenta, stránka i všechny její verze zmizí ze serverů, na kterých byly. Kopie, kterou si někdo uložil do vlastního zařízení, mu zůstane, ale bez odkazu se nedá přečíst.

Volitelně: strážce mimo model.

Nástroj už sám odmítne zveřejnit nešifrovanou stránku, pokud se to po něm nechce dvakrát. Pokud to chceš modelu úplně vzít z rukou, přidej strážce jako hook. Zablokuje každý příkaz, který by zveřejňoval veřejně nebo jiným nástrojem, a každý pokus přečíst soubor s klíči stránek. Pro Claude Code do ~/.claude/settings.json:

{
  "hooks": {
    "PreToolUse": [
      { "matcher": "Bash|Read",
        "hooks": [ { "type": "command",
                     "command": "node ~/.claude/skills/nsite-artifacts/hooks/guard.mjs" } ] }
    ]
  }
}

I servery si vybíráš sám. Ve výchozím stavu jdou stránky na veřejné relaye a na nostr.download a blossom.yakihonne.com. Pokud chceš jiné, zapiš je do ~/.config/nsite-clay/artifacts/config.json. Stejná složka drží klíče všech stránek, které agent udělal, tak ji nikomu nedávej a zálohuj si ji, pokud ti na stránkách záleží.
