Who is publishing?

A site belongs to a key, not to an account. Whichever key signs in here becomes the only one that can change the page afterwards.

The key stays in this tab's memory for as long as it is open and is never written anywhere. A signer app is safer, because the key never reaches the page at all.

This is your new key. It is the only thing that can ever change your site. Nobody can reset it and nobody else has a copy.

The file is encrypted with this password using NIP-49. Losing the password loses the key, exactly like losing the key itself.

Where should it live?

Your site is at your npub on any nsite gateway. This is the path inside it. Leave it as a single slash for the front page.

Relays and Blossom servers

One per line. Relays hold the pointer to your site and Blossom servers hold the bytes, so more of each is more places your page survives. The defaults work; change them if you run your own, or if one of them is refusing you.

Publishing

Each file becomes a Blossom blob, then one signed manifest says which blob each path points at. Your signer may ask you to approve each signature.
